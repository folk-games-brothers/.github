# Folk Games Studio

Personal GitHub organization for experiments, games, tooling, and shared automation.

## Focus

- Game prototypes and small projects
- Shared GitHub Actions workflows
- Reusable composite actions
- Developer tooling and templates

## Repositories

- [`lototet`](https://github.com/folk-games-brothers/lototet): main project
- [`.github`](https://github.com/folk-games-brothers/.github): default community health files and reusable workflows
- [`actions`](https://github.com/folk-games-brothers/actions): shared composite actions

## Standards

- Default branch: `master`
- Branch naming: `feature/*`, `fix/*`, `docs/*`, `chore/*`, `release/*`, ...
- Pull requests are required for `master`
- Squash merge only
- No direct push to `master`
